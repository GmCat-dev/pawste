# Security

If you find a security problem in Pawste (for example a way to read a private paste without its link, to edit or
delete someone else's paste, or to run code on paw.gmcat.io), please report it privately:

**GitHub → this repository → Security → "Report a vulnerability".**

Please include steps to reproduce. We'll reply as soon as we can and credit you if you'd like.
Please don't test against other people's pastes, and don't run load tests against paw.gmcat.io.

Out of scope: anything that needs the full private link (the link *is* the key), denial of service, and reports about
the short-link mode not being encrypted (that's by design and clearly labelled).
