Pawste · Free tool

Code to Image

Turn code into a clean, shareable picture for X, Discord, slides or docs. Free, no sign-up, and made right in your browser.

Made on your device: your code isn't uploaded. Pictures are 2400 pixels wide (sharp on any screen) and show up to 60 lines.

Good to know

Is my code uploaded?

No. The picture is drawn in your browser, so your code never leaves your device unless you choose “Share the code as a paste”.

Which languages are coloured?

About 30, including JavaScript, TypeScript, Python, Go, Rust, Java, C, C++, C#, PHP, Ruby, Swift, Kotlin, SQL, HTML, CSS, JSON, YAML, Bash and Markdown. “Detect automatically” guesses for you.

How big is the picture?

2400 pixels wide (twice the size it's shown, so it stays sharp on phones and high-resolution screens). The height grows with the number of lines, up to 60.

Can I remove the small Pawste mark?

The little “Pawste · paw.gmcat.io” mark stays in the corner. It's how people find the tool, and it keeps it free.

Does it work offline or on a phone?

It works on phones and tablets. Once the page has loaded, making pictures doesn't need the internet.
