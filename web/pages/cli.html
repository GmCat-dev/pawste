Pawste · Command line

Pawste from the command line

Share a file or command output straight from your terminal and get a short link back. No account, no API key.

Quick start

Send anything to Pawste and get a short link back:

echo "GM, Cat Crew!" | curl --data-binary @- https://paw.gmcat.io
curl --data-binary @notes.txt "https://paw.gmcat.io/?ttl=1d&title=Notes"

The reply is the link, like https://paw.gmcat.io/k7m2x9pq. Read it back as plain text with:

curl https://paw.gmcat.io/raw/k7m2x9pq

⚠ Pastes from the command line use short links, which aren't encrypted. For passwords and secrets, use the secure note page instead.

Options

Add to the addressWhat it does
?ttl=1dHow long to keep it: 10m, 1h, 1d, 1w (default), 1m, 6m or 1y
&burn=1Delete it the first time it's opened in a browser (raw reading is turned off for these)
&title=NotesA title
&lang=pythonCode colouring (otherwise it's detected)
&force=1Share even if Leak Guard thinks it contains a password or key

Leak Guard, in your terminal

If what you send looks like it contains a password, an API key, a private key or a card number, Pawste doesn't share it and tells you what it found. Remove it, or add force=1 if you're sure.

Edit or delete

Each reply also carries an edit link in the X-Pawste-Edit header (see it with curl -i). Open it in a browser to edit, or delete from the terminal:

curl -X DELETE -H "X-Edit-Token: YOUR_TOKEN" https://paw.gmcat.io/api/pawste/k7m2x9pq

Want everything at once? Ask for JSON:

curl -H "Accept: application/json" --data-binary @notes.txt https://paw.gmcat.io

The pawste helper

A tiny script (bash + curl) that does the typing for you. Read it first, then install it:

curl -fsSL https://paw.gmcat.io/cli.sh -o ~/.local/bin/pawste && chmod +x ~/.local/bin/pawste
pawste notes.txt            # share a file
make 2>&1 | pawste -t 1d    # share command output for a day
pawste -b notes.txt         # burn after reading

Good to know

Is there a limit?

Each paste can be up to 512 KB of text. To keep things fair, each address can make up to 30 pastes an hour.

Why aren't command-line pastes encrypted?

Private links are locked by the browser before they leave your device, which a plain curl can't do. So the command line uses short links, and Pawste labels them as not encrypted.

Does it need an account or a key?

No. It's free, with no account and no API key.

Can I use it in scripts and CI?

Yes. The reply is just the link on one line, so LINK=$(cmd | curl --data-binary @- -s https://paw.gmcat.io) works. Please don't use it to store logs that contain secrets.
