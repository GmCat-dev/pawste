# Pawste 🐾

The code behind **[Pawste](https://paw.gmcat.io)**, a free paste bin from [GmCat](https://gmcat.io): no ads, no account,
private by default.

- **Private links** are encrypted in your browser (AES-256-GCM, Web Crypto). The key lives in the link after `#`, which
  browsers never send to a server, so the server only stores scrambled text.
- **Short links** (`paw.gmcat.io/k7m2x9pq`) are optional and always labelled as not encrypted. Add a password and the
  paste is locked with a key made from the password (PBKDF2-SHA-256, 600,000 rounds).
- **Leak Guard** spots passwords, API keys, private keys and card numbers before you share.
- **Burn after reading** that chat-app link previews can't trigger, **edit history** with diffs, **line links**,
  **Markdown**, **code pictures** ([Code to Image](https://paw.gmcat.io/code-to-image/)) and **curl** support.

This repository is published so anyone can check how Pawste handles their text. Plain-language explanation:
**[How Pawste keeps pastes private](https://paw.gmcat.io/security/)**.

## Where to look

| What | File |
|---|---|
| Locking and unlocking (the crypto) | [`web/js/pawste-core.js`](web/js/pawste-core.js) — `P.lock`, `P.unlock`, `aesKey` |
| Leak Guard (browser) | `web/js/pawste-core.js` — `P.scan`, `P.redact` |
| Editor / reader | `web/js/pawste.js`, `web/js/pawste-view.js` |
| Code pictures | `web/js/pawste-snippet.js`, `web/js/code-to-image.js` |
| The service (Python standard library + SQLite) | [`server/server.py`](server/server.py) — the API is listed at the top |
| What the server stores | `server/server.py` — `init()` (tables) |
| Tests | `python3 server/test_server.py` |
| Command-line helper | [`cli/pawste.sh`](cli/pawste.sh) |
| Example Nginx setup | `server/nginx-example.conf` |

`web/pages/` holds the built pages exactly as paw.gmcat.io serves them (they're generated by GmCat's site builder,
which isn't part of this repository).

## Use it from a terminal

```sh
echo "GM, Cat Crew!" | curl --data-binary @- https://paw.gmcat.io
curl https://paw.gmcat.io/raw/<code>
```

Command-line pastes use short links and aren't encrypted. Details: https://paw.gmcat.io/cli/
